# DNX Template Studio v3 — Demo

Premium React/Vite demo for generating Goodnotes-ready digital templates.

Templates:
- Linked Notebook
- Annual Planner
- Task List
- Weekly Planner

Languages: EN / DE / ES

The interface is explicitly marked as a DEMO. Generated templates are demonstration assets for DNX Lab.

Run:
npm install
npm run dev

Build:
npm run build

Production route:
https://tools.dnxlab.de/template-studio
